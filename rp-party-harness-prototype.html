START HERE
Your first scene

      

        
Party Harness is a story space for you and a party of AI-controlled characters. Write an action, let the scene respond, and decide what happens next. You can browse and edit without a key; generating text needs a hosted provider or a running local model server; art uses a hosted image provider or a compatible local server.

        
  1. Connect: open SETTINGS, find Text generation connection, choose a provider and model, and enter its API key if required. Ollama and LM Studio can run locally without a key. Leave the custom roleplay backend URL blank.
  2. Set the scene: NEW SESSION offers presets or your own premise. Choose whether you play the first party member or direct the party as an unseen narrator (DM).
  3. Meet the party: open a character sheet to edit their name, pronouns, personality, portrait, and abilities. Party order determines who you play in party-member mode.
  4. Take a turn: write an action and SEND TURN. Enter sends; Shift+Enter adds a line. Suggestions are optional. CONTINUE reveals the next part of a response; a choice or dice check may need your input first.
  5. Keep a copy: SESSIONS lets you name saves and export a session JSON file for backup or transfer.

        
What do the story controls mean?
Undo turn restores the previous exchange and your action. Regenerate tries that action again and makes another provider request. Cancel stops waiting for a reply; a provider may already have processed the request. Use the pencil beside generated text to correct it.
A beat is one part of a response. Characters can speak when it fits the scene; silence is valid. Images are optional and generated only when you request them.

        
World state, memory, and canon
World state tracks things such as inventory, conditions, relationships, and objectives. EDIT corrects an entry. A clock is a progress counter; a flag records a fact or event.
Memory proposals are suggestions to review, not automatic personality changes. Reactions can expire; relationship memories and development can persist. Pinned canon means facts you explicitly ask the story to respect. The running summary is an AI-written recap and can be imperfect.

        
Where is my story saved?
Autosave and named saves stay in this browser on this computer. Use the same address and port to find them again. Clearing browser site data can remove them. Export session JSON for a portable backup; export Markdown for a readable story. Session exports exclude API keys and generated art. Save art separately if you want to keep it.
Your selected provider receives the story context needed to generate replies. Local storage does not mean offline generation. Uploaded reference images are sent when used for image generation.

        
Something is not working
Keep the server terminal open. If connection fails, check SETTINGS and the terminal, confirm your provider and model, and restart after editing .env. A ready indicator confirms configuration, not provider account access. If saving needs attention, export your session before closing the page. See README.md in the download for setup and troubleshooting.
